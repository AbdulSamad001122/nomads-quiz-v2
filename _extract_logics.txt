[0474] The calculator
[0475] Runs silently. It produces the current RPV, the goal RPV, a set of goal metrics, and the numbers the results page needs. The taker never sees any of this math.
[0476] 
[0477] 1 · The five metrics
[0478] Five metrics feed RPV. Four can be improved; order value is fixed.
[0479] Metric
[0480] Source
[0481] Can improve?
[0482] Opt-in Rate
[0483] Q8 ÷ Q7
[0484] yes
[0485] Lead Conversion Rate
[0486] Q9a
[0487] yes
[0488] Close Rate
[0489] Q9b
[0490] yes
[0491] Revenue Per Subscriber™ (RPS)
[0492] Q11 ÷ annual subscribers
[0493] yes
[0494] Order value/deal size
[0495] Q10
[0496] no — fixed
[0497] 
[0498] 2 · Current numbers
[0499] Annual Visitors        = Q7 value × 12
[0500] Current Annual Revenue  = Q2 value   (already annual — no ×12)
[0501] Current RPV            =  Current Annual Revenue ÷ annualVisitors
[0502] Annual Subscribers     = Annual Visitors × OptIn Rate
[0503] OptIn Rate             = Q8 value ÷ Q7 value
[0504] Lead Rate              = Q9a value
[0505] Close Rate             = Q9b value
[0506] Order Value            = Q10 value
[0507] RPS                   = Q11 value ÷ annualSubscribers
[0508]  // Note: There’s one revenue source. Q2. RPV is the annual figure. The 14-day window in the questions is only the benchmark window for lead conversion — it is not part of the revenue figure.  // 
[0509] 3 · The goal
[0510] Target Revenue        = Current Annual Revenue + 1,500,000
[0511] Additional RPV needed  = 1,500,000 ÷ Annual Visitors
[0512] Goal RPV              = Current RPV + Additional RPV Needed
[0513]  // 4 · Ceilings
[0514] Metric
[0515] Ceiling
[0516] Opt-in Rate
[0517] 0.60
[0518] Lead Conversion — PLG
[0519] 0.30
[0520] Lead Conversion — SLG
[0521] 0.22
[0522] Close Rate
[0523] 0.75
[0524] Revenue Per Subscriber™
[0525] $50
[0526]  // 5 · The improvement loop
[0527] A round-robin that raises one metric at a time until the goal is reached or every metric is maxed. Deterministic, so the same answers always produce the same result.
[0528] Before the loop:
[0529] Any metric already at/above its ceiling → set to ceiling, freeze.
[0530] If RPS = 0 → freeze it, run on three metrics.
[0531] Clamping: a goal value is never returned below the current value. If it would be, hold at current.
[0532] The cycle — fixed order, repeat until it stops:
[0533] order = [ closeRate, leadRate, optInRate, RPS ]
[0534] for each metric in order:
[0535]     if frozen: skip
[0536]     candidate = currentValue × 1.1          // multiplicative: a tenth of current
[0537]     if candidate ≥ ceiling: set to ceiling, freeze
[0538]     else: set to candidate
[0539]     evaluate revenue()                     // after EVERY adjustment
[0540]     if revenue ≥ targetRevenue: STOP       // these are the goal values
[0541]  // Revenue evaluation:
[0542] Annual Subscribers = annual Visitors × optIn Rate
[0543] List Revenue       = annual Subscribers × RPS
[0544] Non List Revenue = current Annual Revenue − current List Revenue   // fixed before the loop
[0545] revenue           = List Revenue + non List Revenue
[0546]  // Note: ×1.1 is multiplicative (0.25 → 0.275 → 0.3025), not +0.1. RPS already includes the subscriber’s purchase value, so lead and close rates live inside RPS — never add the funnel product beside it. Non List Revenue is fixed once and never recalculated. No rounding inside the loop.
[0547] Two endings:
[0548] Goal reached — stop on the adjustment that hits it. Those are the goal values. (Results Block 4.)
[0549] Everything maxed, goal not reached — go to the capped-state maths under Results-page logic. (Results Blocks 5–7.)

[0632] 6 · Blocks 5–7 — Capped states
[0633] Maths for all three:
[0634] Max RPV     = (annual Visitors × optIn Ceiling × rps Ceiling + non ListRevenue) ÷ annual Visitors
[0635] Achievable Gain  = (annual Visitors × max RPV) − current Annual Revenue
[0636] Remaining Gap   = 1,500,000 − achievable Gain
[0637] Additional Daily Visitors = (remaining Gap ÷ max RPV) ÷ 365      // divide by max RPV, not current RPV
[0638]  // Guards: if achievable Gain ≤ 0, set to 0 and suppress any sentence containing it. Round money to nearest $100, visitors to nearest 100 (display only). Show traffic as a daily number.
