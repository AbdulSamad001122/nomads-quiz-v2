Booking reminder tags: setup guide

A Google Apps Script that adds Kit reminder tags 48 hours, 24 hours and 1 hour before each person's TidyCal call. Kit then sends the matching email.

1. How it works

  1. Nomads' Zapier + Kit setup tags each quiz-call booker Quiz Booked a Call and saves the call time in the Kit field Booking Time & Date Raw (e.g. 2026-10-09T12:30:00.000000Z, UTC).
  2. Every 15 minutes the script reads everyone with that tag, works out how many hours are left until each call, and adds:
    When the call is…Tag added
    48 hours away or lessQuiz Call 48 hour reminder
    24 hours away or lessQuiz Call 24 hour reminder
    1 hour away or lessQuiz Call 01 hour reminder
  3. Each tag is added once. If a person already has it, they're skipped.
  4. Late bookings: only the closest reminder is sent. Booked 20 hours ahead → only the 24h reminder now, then the 1h one. The 48h reminder is never sent for them.
  5. Kit automations (Nomads' side) send each email the moment its tag is added.
Timing: the script checks every 15 minutes, so emails can be up to 15 minutes late. Zapier on the free plan also checks TidyCal every 15 minutes, so a brand-new booking can take up to about 30 minutes to be picked up.

2. Before switching on (Nomads, in Kit)

  1. Build the 3 email automations: "tag Quiz Call 48 hour reminder added → send the 48h email", and the same for 24h and 01h.
  2. Build them before the script is switched on. People who already have a tag when an automation is created don't go through it.
  3. The tag names must stay exactly as they are. The script only looks tags up and never creates them, so if a name changes it stops and reports an error.

3. Install (on the Nomads Google account)

  1. Sign in to the Nomads Google account and open script.google.com → New project. Name it Booking reminder tags.
  2. Delete the sample code in Code.gs and paste in the full contents of booking-reminders/Code.gs from the repo. Save.
  3. Project Settings (gear icon):
    • Tick Show "appsscript.json" manifest file in editor, open it, and replace it with booking-reminders/appsscript.json. Save.
    • Under Script Properties → Add script property: name KIT_API_SECRET, value = the Kit v3 API Secret (Kit → Settings → Developer). Use the current secret. The one written in the "Important Settings" doc is an old one.
  4. Choose dryRun in the function menu at the top and press Run. Google asks for permission the first time: allow it (it needs "connect to an external service" and "manage triggers").
  5. Open Executions (left menu) and read the log. It lists everyone booked and what it would add. Nothing is added in a dry run.
  6. When the dry run looks right, choose setup → Run. It checks the secret and all 4 tag names, then switches on the 15-minute timer. Done.

5. Known limits (agreed for now)

  • Cancellations and reschedules are not handled. If someone cancels, they still get the reminders. If someone reschedules and Kit's field isn't updated, the reminders follow the old time.
  • Repeat bookers: someone who books a second call later already has the reminder tags from the first one, so they won't get reminders again unless those tags are removed in Kit by hand.
  • A call booked less than about 1 hour ahead may get no 1h reminder (Zapier delay + 15-minute checks).
  • The script only tags active Kit subscribers (unsubscribed people can't be emailed anyway).
  • It uses Kit API v3, the same as the quiz. Kit calls v3 "deprecated" but hasn't set a shutdown date.

6. Safety

  • The Kit secret is only in Script Properties, never in the code. The code in the repo has no secrets.
  • Don't share the Apps Script project with people who shouldn't see the Kit secret: anyone who can edit the project can read Script Properties.
  • The code (booking-reminders/_reminders.test.js) is covered by 52 automatic checks: run node booking-reminders/_reminders.test.js.
